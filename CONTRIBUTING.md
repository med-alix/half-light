# Contributing

HALF-LIGHT is designed in the open. Everything in this book is a draft position, and the best way to change it is to challenge it with an argument, a number or a simulation.

## Ways to help

| You can... | How |
| --- | --- |
| Propose a design change | Open an issue with the **Design proposal** template |
| Share a simulation result | Open an issue with the **Simulation result** template, with your inputs and code |
| Ask a question | Open an issue with the **Question** template |
| Fix or improve the docs | Open a pull request that edits the files in `docs/` |
| Build | Front-end, indexer, contracts, art, writing: say hello in an issue |

## Ground rules

1. **Protocol is physics.** Any proposal that touches the protocols must say which contract rule it relies on.
2. **Numbers beat adjectives.** If a proposal changes balance or tokenomics, show the effect with the model or the sims, or say what should be simulated.
3. **No losers-pay-winners mechanics.** Every cost in the game is a burn; players keep what the protocols pay them.
4. **Be kind.** Disagree with ideas, not people.

## How decisions are made

Each open question has a draft position in [Open questions](docs/open-questions.md). When a discussion reaches rough agreement, a maintainer moves it to **Decided** with a link to the discussion. Nothing launches on chain without the [launch gates](docs/granary/launch-gates.md).

## Running the simulations

Python 3 with numpy and matplotlib:

```bash
cd sim
pip install numpy matplotlib
python run_scenarios.py
```

Open `sim/game/half-light-simulator.html` in a browser to play seasons.

## Editing the book

The book is plain Markdown in `docs/`, published with Docusaurus (in `website/`) to https://med-alix.github.io/half-light/ on every push to `main`. The table of contents and sidebar order is `docs/SUMMARY.md`: add new pages there. To preview locally, run `npm install` then `npm start` inside `website/`. Diagrams live in `docs/assets/diagrams/` and are generated by `tools/make_diagrams.py`; edit the script and rerun it rather than editing the SVGs by hand.
